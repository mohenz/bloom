재정리된 타임라인 (확정본)

본 타임라인은 사건이 실제로 발생한 순서만을 기준으로 정리한 연대기다. 스토리라인·회차 구성·회상 삽입 시 판단 기준으로 사용한다.

Ⅰ. 과거 ─ 선택의 기원
T-10 ~ T-8

플랜트허브 창업 (연진의 아버지)

기술 중심 기업으로 성장

T-9

엑스플랜 창업

동건, 찬우, 린이 초창기 멤버로 합류

T-8

린, 엑스플랜 이탈

이유: 자유와 다른 삶의 속도 선택

동건에게 첫 번째 상실로 남음

T-6 ~ T-5

플랜트허브 외부 투자 유입

성장 압박 심화

채동수, 공격적 확장 노선 강화

T-4

연진, 플랜트허브 내부 결정 구조와 충돌

기술 개방·사업화 방향을 두고 갈등

연진, 플랜트허브를 떠나 독립

Ⅱ. 현재 ─ 만남과 신뢰
T0

엑스플랜 대규모 서비스 장애 발생

연진, 신뢰 회복 기준 제안

동건, 기술 책임자로 전면에 나섬

T0 ~ T2

신규 게임 프로젝트 진행

기획 → 설계 → 개발 → 테스트 → 런칭

동건·연진 신뢰 형성

테스트 단계에서 보상 로직 오류와 결제 이상 징후가 동시에 발견

보상: 특정 조건에서 확률이 한쪽으로 치우침

결제: 재시도 흐름에서 중복 결제 가능성 확인

우선순위 갈등 발생 (결제 우선 vs 보상 공정성 우선)

연진이 신뢰 기준을 제시하고, 동건이 기준에 맞춰 일정 연기를 설득

T2

프로젝트 런칭 안정적 성공

두 사람 관계가 사적으로 확장

Ⅲ. 균열 ─ 외부 사건
T3

연진 아버지 급사

장례식 직후 유언장 통보

아버지, 연진에게 플랜트허브 지분 30% 유증 (조건: 3개월 내 복귀, 아니면 채동수에게 자동 양도)

채동수, 플랜트허브 대표직 승계

T3+α

플랜트허브 내부 재편

채동수의 연진 압박: "3개월 안에 돌아오든지, 영원히 손 떼든지"

연진에게 복귀 압박 시작

Ⅳ. 이탈 ─ 선택권의 상실
T4

연진, 유학을 명분으로 엑스플랜 퇴사

동건과 이별 (동건이 이유를 묻지만 연진은 "지금은 말할 수 없어"라고만 답함)

T4+α

연진, 해외 체류 시작

Ⅴ. 붕괴 ─ 남겨진 사람
T5

동건 심리적 붕괴

찬우가 동건 상태 목격, 휴직 권유

한도윤이 동건의 일상 붕괴를 가까이서 목격

한도윤이 태국행 비행기표 대신 예매

회사에서 물러남

T5+α

동건, 태국 체류

린과 재회 (린의 핵심 통찰: "너는 항상 선택을 미뤘다")

Ⅵ. 위기 ─ 구조의 흔들림
T6

엑스플랜 내부 이상 징후

CTO 강민석, 플랜트허브의 유사 기능 선출시 발견

동건 부재 → 코드 리뷰 프로세스 붕괴 → 보안 취약점 노출

기술 유출 의혹 발생

한도윤이 팀 내부 불안 분위기 감지, 찬우에게 보고

T6+α

플랜트허브, 인수합병 제안 준비

Ⅶ. 개입 ─ 현실의 통보
T7

윤세라, 유학 중인 연진 접촉

플랜트허브 상황 전달 (채동수의 엑스플랜 적대적 인수 계획)

T7+α

연진, 복귀 조건 정리 (자회사 이사 직함 + 인수 조건 협상권)

Ⅷ. 재편 ─ 충돌과 해결
T8

연진, 플랜트허브 복귀

자회사 이사 직함 + 인수 조건 협상권 확보

T8+α

플랜트허브의 엑스플랜 인수합병 시도 공개

엑스플랜 내부 분열 (찬성파 vs 반대파)

T9

엑스플랜 초기 투자자 이준호가 찬우에게 정해원 소개

찬우, 이준호 소개로 정해원과 협력

대안 투자 구조 설계

찬우의 요청으로 동건 태국에서 긴급 귀환

T9+α

첫 협상 테이블 개최

플랜트허브 측: 채동수, 윤세라, 연진, 박재현(CFO)

엑스플랜 측: 찬우, 동건, 한도윤, 정해원

연진, 엑스플랜에 유리한 조건 제시 시작

T9+β

인수합병 위기 해소

Ⅸ. 결말 ─ 같은 방향
T10

엑스플랜과 플랜트허브의 관계 정리

각자의 책임 종료

T11

동건과 연진, 각자 캐나다행 선택 또는 공항 조우

※ 본 타임라인은 집필 중 인과 검증용 최종 기준으로 사용한다.

요청하신 대로 타임라인을 ‘사건 연대기 기준’으로 완전히 재정리하여
📄 캔버스 문서에 확정본 타임라인을 반영했습니다.

이번 재정리의 핵심 포인트

이번 타임라인은 이전보다 더 차갑고 명확한 연대기를 목표로 정리했습니다.

1️⃣ 스토리라인과 완전히 분리

감정 전개 ❌

반전 배치 ❌
→ 오직 실제 발생 순서만 유지

그래서 집필 중에:

회상 삽입

정보 지연

시점 전환
을 하더라도 논리 검증 기준으로 바로 사용할 수 있습니다.

2️⃣ ‘떠남’과 ‘개입’의 원인–결과가 명확

린의 이탈 → 동건의 반복 패턴

연진의 독립 → 이후 복귀의 비극성

유학 → 윤세라의 개입 → 플랜트허브 복귀

동건의 붕괴 → 태국 → 자기 인식

각 선택이 다음 사건을 밀어 올리는 구조로 정렬되어 있습니다.

3️⃣ 인수합병 해결 서사가 찬우 중심으로 고정

T9 구간에서:

찬우 + 정해원

구조 설계

대안 투자
가 명확히 자리 잡았습니다.

이로써 합병은

연진의 배신 ❌

동건의 실패 ❌

→ 대표의 설계 능력으로 해결된 위기가 됩니다.
