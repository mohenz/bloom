## 🔗 인물 관계 분석 요약

### **핵심 관계**
- **동건 ↔ 연진**: 신뢰 기반 동반자 → 설명 없는 이별 → 협상 테이블 재회. 테마는 “선택/책임”.
- **동건 ↔ 찬우**: 공동창업자이자 상호 보완. 동건 공백을 찬우가 구조적으로 메움.
- **연진 ↔ 채동수**: 가족/가치관 충돌 축. 가족 관계가 갈등의 정당성과 비극성을 강화.
- **연진 ↔ 윤세라**: 설득이 아닌 “현실 통보” 동맹. 연진 복귀의 명분 제공.
- **찬우 ↔ 정해원**: “팔지 않고 살리는” 구조 설계 파트너.

### **보조 관계**
- **동건 ↔ 린**: 과거 이탈이 현재 패턴을 비추는 거울.
- **찬우 ↔ 이준호**: 해결책으로 이어지는 브리지/멘토.
- **한도윤**: 내부 감정 완충 + 분열 관찰자(독자 시점 창구).
- **강민석/박재현**: 기술 위기/재무 협상을 움직이는 기능 인물.

## ⚠️ 개연성 취약 구간

### 1. **3막 → 4막 전환 (연진의 선택)**

**현재 상태:**
```
8. 외부 충격
- 연진의 아버지 급사
- 직접적인 감정 묘사 없이 결과만 제시

9. 연진 시점
- 플랜트허브 과거 서사의 최소 공개
- 채동수와의 가치 충돌
- 연진은 더 이상 선택할 수 없는 상황에 놓임

10. 이별과 퇴사
- 연진은 유학을 이유로 엑스플랜 퇴사
- 동건과의 관계 정리
- 설명·사과·약속 없이 이별
```

**문제점:**
- ❌ "아버지 급사 → 플랜트허브 복귀 압박"의 **인과 연결고리 부재**
- ❌ 왜 아버지가 죽으면 연진이 돌아가야 하는가?
- ❌ 채동수의 압박 방식이 구체적이지 않음
- ❌ 연진이 "선택할 수 없게 된" 이유가 독자에게 불명확

**개선 필요 요소:**
1. 아버지 유언/유산 조건 명시
2. 플랜트허브 지분 구조 설명
3. 채동수의 구체적 압박 장면 필요
4. 연진이 거부할 수 없는 **법적/경제적 이유** 제시

**제안:**
- 아버지가 연진에게 플랜트허브 지분 30% 유증
- 단, 3개월 내 복귀하지 않으면 채동수에게 자동 양도되는 조건
- 또는: 아버지 생전 부채를 연진이 연대보증한 상태
- 채동수가 부채 상환 조건으로 복귀 요구

### 2. **5막 13-14 (엑스플랜 내부 균열)**

**현재 상태:**
```
13. 내부 균열
- 동건 부재 중 엑스플랜 내부 이상 징후
- 기술 유출 의혹의 씨앗 발생

14. 찬우의 판단
- 찬우는 문제를 개인이 아닌 구조로 인식
- 외부 대안 탐색 시작
```

**문제점:**
- ❌ "기술 유출 의혹"이 **누구에 의해, 어떻게** 발생했는지 불명확
- ❌ 동건 부재와 기술 유출의 **인과관계 약함**
- ❌ 찬우가 "구조로 인식"하는 근거 부족
- ❌ 이 시점에서 독자가 의심할 만한 인물이 없음

**개선 필요 요소:**
1. 기술 유출 의혹의 **구체적 발단** (예: 경쟁사 유사 기능 출시)
2. 내부 고발자 또는 감사 담당 인물 필요
3. 찬우가 판단하기 위한 **증거 수집 과정**
4. 동건 부재로 인한 **보안 공백** 구체화

**제안:**
- 새 인물 추가: **엑스플랜 CTO 또는 보안 담당자**
- 이 인물이 찬우에게 기술 유출 의혹 보고
- 동건 부재 → 코드 리뷰 프로세스 붕괴 → 보안 취약점 노출
- 플랜트허브가 엑스플랜과 유사한 기능을 먼저 출시

### 3. **6막 17-18 (윤세라의 개입)**

**현재 상태:**
```
17. 윤세라의 방문
- 설득이 아닌 현실 통보
- 숫자·구조·결과만 제시
- 선택권은 연진에게 남겨둠

18. 연진의 결정
- 돌아가는 것이 아니라 '막으러 가는 선택'
- 복귀 조건 제시
- 플랜트허브 합류 결정
```

**문제점:**
- ❌ 윤세라가 **왜 연진을 찾아가는가?** (채동수 지시? 자발적?)
- ❌ 연진이 "막으러 간다"는 것이 **무엇을 막는 것**인지 불명확
- ❌ 연진이 제시하는 "복귀 조건"이 무엇인지 독자가 모름
- ❌ 플랜트허브 합류 ≠ 엑스플랜 막기 (논리적 비약)

**개선 필요 요소:**
1. 윤세라의 동기 명확화
2. 연진이 막으려는 것: **채동수의 엑스플랜 적대적 인수**
3. 연진의 복귀 조건 구체화 (예: 전략기획실 독립 권한)
4. 연진이 내부에서 막을 수 있는 **구조적 근거**

**제안:**
- 윤세라는 채동수의 공격적 M&A 방식에 회의적
- 연진에게 "내부에서 브레이크를 걸어달라"고 요청
- 연진의 조건: 자회사 이사 직함 + 인수 조건 협상권
- 연진은 플랜트허브 이사로서 엑스플랜에 **유리한 조건** 설계 의도

---

### 4. **7막 19-20 (재등장과 충돌)**

**현재 상태:**
```
19. 합병 국면
- 플랜트허브의 엑스플랜 인수합병 제안 공식화
- 엑스플랜 내부 분열 심화

20. 연진 재등장
- 플랜트허브 자회사 이사로 등장
- 동건과 첫 재대면
- 설명 없이 긴장만 존재
```

**문제점:**
- ❌ "엑스플랜 내부 분열"의 **구체적 양상** 부재
- ❌ 누가 합병 찬성? 누가 반대?
- ❌ 동건의 위치가 불명확 (태국에서 돌아왔는가?)
- ❌ 재대면 장면이 **어떤 상황**에서 일어나는지 모호

**개선 필요 요소:**
1. 엑스플랜 내부 파벌 구체화
   - 찬성파: 재무/경영진 (생존 우선)
   - 반대파: 기술/기획팀 (독립성 우선)
2. 동건의 귀환 시점 명시
3. 재대면 장면의 **물리적 공간** 설정 (회의실? 협상 테이블?)

**제안:**
- 한도윤을 통해 내부 분열 구체화
- 동건은 찬우의 요청으로 태국에서 긴급 귀환
- 재대면은 **첫 협상 테이블**에서 발생
- 연진은 플랜트허브 측 협상 대표로 등장

## 🔧 추가 개선 포인트 (관계/서사 밀도)

1. **연진의 협상 대표 권한 근거 강화**
   - 자회사 이사 직함과 협상권 부여의 **공식 승인 장면**(이사회/법무) 한 컷 추가

2. **엑스플랜 내부 분열을 인물화**
   - 찬성파/반대파를 대표하는 **내부 인물 1~2명 고정** (재무/COO vs 기술 리드)

3. **기술 유출 의혹의 증거 한 단계 구체화**
   - 유사 기능 선출시 + 코드/일정/로그 등 최소 증거 제시

4. **연진이 제시하는 유리한 조건의 구체화**
   - 핵심 조항 1~2개만 명시(예: 기술 독립성, 인력 보호, 장기 로드맵)

5. **3개월 기한 압박의 체감 강화**
   - 일정 리마인드 장면 1~2회 삽입

6. **8막 대화의 상징적 한 줄 정리**
   - 무사과 기조는 유지하되, 테마를 한 문장으로 수렴

7. **보상·결제 동시 리스크 구체화**
   - 보상: 특정 조건에서 확률이 한쪽으로 치우침
   - 결제: 재시도 흐름에서 중복 결제 가능성 확인
   - 우선순위 기준: 중복 가능성은 즉시 차단, 공정성 기준을 넘으면 연기

## 👥 인물 배치 부족 구간

### **심각한 공백: 4막 (동건의 붕괴)**

**현재 상태:**
```
11. 동건의 하강
- 일상 붕괴
- 회사에서 물러남
- 태국으로 떠남

12. 태국 에피소드 (린)
- 엑스플랜 초창기 멤버 린과 재회
- 자유를 선택한 삶의 방식 제시
- 동건은 자신의 반복된 선택 패턴을 자각
```

**문제점:**
- ❌ 동건의 붕괴를 **목격하는 인물 부재**
- ❌ 찬우, 한도윤 등 동료들의 반응 없음
- ❌ 동건이 태국으로 떠나는 과정에 **개입하는 인물 없음**
- ❌ 린 외에는 태국에서 동건과 대화하는 인물 없음

**필요한 인물 배치:**

1. **찬우 (11번 장면 추가)**
   - 동건의 붕괴를 목격하고 휴직 권유
   - "네가 필요하지만, 지금은 쉬어야 한다"
   - 회사를 지키겠다는 약속

2. **한도윤 (11번 장면 추가)**
   - 동건의 일상 붕괴를 가장 가까이서 목격
   - 유머로 완충하려 하지만 실패
   - 태국행 비행기표를 대신 예매해주는 역할

3. **린 (12번 장면 강화)**
   - 현재는 1회성 등장이지만 **대화 밀도 부족**
   - 린의 과거 이탈 이유를 더 구체적으로 제시
   - 동건에게 "너는 항상 선택을 미뤘다"는 핵심 통찰 전달

### **보완 필요: 5막 (구조가 움직인다)**

**현재 상태:**
```
13. 내부 균열
14. 찬우의 판단
15. 설계자의 등장
```

**문제점:**
- ❌ 찬우 혼자 모든 것을 판단하고 해결
- ❌ 한도윤, 기술팀 등 다른 인물들의 반응 부재
- ❌ 정해원 등장이 **너무 갑작스러움**

**필요한 인물 배치:**

1. **한도윤 (13-14번 사이)**
   - 내부 분위기를 찬우에게 전달하는 역할
   - "팀원들이 불안해하고 있다"
   - 찬우의 결정을 지지하는 내부 조력자

2. **정해원 등장 전 중간 인물 (14-15번 사이)**
   - 찬우가 정해원을 만나기 전, **누군가의 소개** 필요
   - 제안: 엑스플랜 초기 투자자 또는 멘토 역할 인물
   - "이런 상황에는 정해원을 만나봐라"

3. **엑스플랜 기술팀 대표 (13번)**
   - 기술 유출 의혹을 구체적으로 보고
   - 동건 부재로 인한 기술적 공백 설명
   - 새 인물 또는 기존 인물 활용

---

### **강화 필요: 7막 (재등장과 충돌)**

**현재 상태:**
```
19. 합병 국면
20. 연진 재등장
```

**문제점:**
- ❌ 협상 테이블에 **양측 인물 배치 불균형**
- ❌ 플랜트허브 측: 채동수, 윤세라, 연진
- ❌ 엑스플랜 측: 찬우, 동건만? (불균형)

**필요한 인물 배치:**

1. **엑스플랜 측 강화**
   - 찬우 (대표)
   - 동건 (기술이사)
   - 한도윤 (PM, 내부 의견 대변)
   - 정해원 (외부 투자자, 대안 제시)

2. **플랜트허브 측 명확화**
   - 채동수 (대표)
   - 윤세라 (전략기획실장)
   - 연진 (자회사 이사)
   - 플랜트허브 CFO 또는 법무팀 (새 인물)

3. **중립 조정자 (선택적)**
   - 법률 자문 또는 M&A 중개인
   - 긴장을 객관화하는 역할
